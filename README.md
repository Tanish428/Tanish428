## 🔐 Cybersecurity Learning Journey

Cybersecurity is an area I am actively exploring through a structured
learning roadmap. My current priority is to understand the fundamentals
before moving into specialist areas.

### Concepts Studied

-   Operating-system fundamentals and university OS laboratory exercises
-   Linux fundamentals and command-line exposure
-   OSI and TCP/IP networking models
-   IP addressing and subnetting
-   Networking concepts and common network services
-   CIA Triad
-   Authentication and authorization
-   Security threats, vulnerabilities, and exploits
-   Risk assessment and introductory security concepts

### Current Learning Focus

-   Core information-security concepts
-   Security controls and defense in depth
-   Transport-layer networking, including TCP and UDP

### Practical Skills I Plan to Develop

-   More hands-on Linux administration and security practice
-   Network traffic analysis using Wireshark
-   Network discovery and enumeration using Nmap
-   Guided cybersecurity labs through TryHackMe
-   Python and shell scripting for security-related tasks

*The practical tools and activities above are learning goals, not claims
of completed labs or professional experience. I will add specific
results after completing and documenting the work.*
